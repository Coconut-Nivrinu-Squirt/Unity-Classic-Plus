# Authors Directory Guide
## There is an unusual AUTHORS structure at play here. We attribute at the component level.
### Attribution Rules
According to which component you contribute to, You must add yourself to that specific AUTHORS file. Each sub-component has a detailed README which has a mirrored copy of the ROOT DIR contribution rules, munus the statements about V0 and V1
Removing existing authors is not allowed.
If the sub-component has its own AUTHORS-DIR, That will be referred to when discovered and properly hyperlinked.
